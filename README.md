# Wedding Invitation - One Page Digital

Website undangan pernikahan digital yang elegan, modern, dan responsif.

## 🚀 Fitur Utama

- ✅ **Desain Elegan** - Nuansa mewah dengan warna gold, beige, dusty pink
- ✅ **Fully Responsive** - Desktop, tablet, mobile
- ✅ **Animasi Halus** - Scroll-triggered animations
- ✅ **Background Music** - Kontrol play/pause
- ✅ **Countdown Timer** - Hitung mundur real-time
- ✅ **Lightbox Gallery** - Zoom foto prewedding
- ✅ **RSVP Form** - Konfirmasi kehadiran + ucapan
- ✅ **Google Maps** - Lokasi acara
- ✅ **SEO Optimized** - Meta tags lengkap
- ✅ **Fast Loading** - Optimized performance
